English translation of **Gakkou de Atta Kowai Hanashi S** for PlayStation, for the Japanese release **SLPS-00404**.

v0.9.0 fixes the stars that appeared in dialogue and adds an **Endings** checklist to the title menu. It includes the unpublished local v0.8.4 and v0.8.5 changes and every fix from v0.8.3.

### What changed since v0.8.3

- **Correct punctuation:** 1,327 wrongly decoded stars in 968 English rows now display **!!** or **!?**, matching the original game's custom font. For example, the reported shout now reads "Get out of here already!!" The extraction and review tools were corrected too.
- **Ending checklist:** choose **Endings** on the title menu, then a storyteller and story, to browse Done/Unseen entries. The checklist tracks 641 distinct final narration branches; routes sharing the same final narration count as one conclusion. This is not an official count of every possible route.
- **Saved progress:** finish the final page to record a conclusion, then use the normal **Save Notes** operation to keep the mark. Marks are shared by the four Notes on a card. Replaying an ending does not increase the total. There is no extra autosave: resetting before a normal save loses new marks.
- **Older saves:** memory-card saves and existing choice marks remain compatible. Endings completed before v0.8.4 cannot be reconstructed from older saves and start as Unseen. Existing local v0.8.4 ending records remain compatible.

### Apply

Use [Retro Trans](https://github.com/retro-trans/retro-trans-tools), DeltaPatcher, or xdelta3. Select the patch that matches your own exact source BIN:

| Your source image | Patch |
|---|---|
| Japanese SLPS-00404 `.bin` | `Gakkou-Kowai-Hanashi-S-English-v0.9.0.xdelta` |
| Published English v0.8.3 `.bin` | `Gakkou-Kowai-Hanashi-S-English-v0.8.3-to-v0.9.0.xdelta` |
| Published English v0.8.1 `.bin` | `Gakkou-Kowai-Hanashi-S-English-v0.8.1-to-v0.9.0.xdelta` |
| Published English v0.8.0 `.bin` | `Gakkou-Kowai-Hanashi-S-English-v0.8.0-to-v0.9.0.xdelta` |

All four patches produce the same v0.9.0 BIN. Keep checksum verification enabled; source sizes and hashes are in `README-v0.9.0.txt` and `BUILD-MANIFEST.json`. No complete game images are distributed.

```text
xdelta3 -d -s "Gakkou de Atta Kowai Hanashi S (Japan).bin" Gakkou-Kowai-Hanashi-S-English-v0.9.0.xdelta "Gakkou de Atta Kowai Hanashi S (English v0.9.0).bin"
```

Copy your original CUE, rename the copy, and change its `FILE` line to refer to the new BIN. For CHD sources, extract your own BIN/CUE first. **Boot the new image fresh and load an in-game memory-card save.** Old emulator save states retain the previous program and file positions.

### Validation and limits

All four patches were applied back to their exact source images and the complete output size and SHA-256 were verified. The v0.9.0 scripts are byte-identical to the checked local v0.8.5 scripts: all 71 match the corrected sources, none of the 16,120 text/choice strings contain encoded stars, and all non-string bytecode, coin paths, 641 ending IDs and 2,794 choice IDs remain intact. The program executable is byte-identical to the local v0.8.4 and v0.8.5 builds; the title background shows v0.9.0. Layout checks found no text outside its window.

On the local v0.8.4 build, muted DuckStation checks executed the actual ending-tracker code for all 157 menu pages and counters, final-page acknowledgement, repeated endings and old/new save-buffer round trips. The BIOS file-write/close entries were intercepted before I/O in those tests; this was not a physical memory-card test. Native menu previews checked category/story lists, pagination and Back. Most stories, the seventh story and their endings have not been played through in English. The new checklist has not received a complete story playthrough test.

The save file keeps its original size and block count; ending marks use spare bytes. The additional code and menu data stay within documented RAM bounds, but every route's use of the expanded heap range and physical PlayStation hardware remain untested. The title logo and a few intentionally illegible or tiny graphics remain Japanese. Some staff-name readings are unconfirmed. At native resolution the dialogue font looks rougher than at higher emulator resolutions.

### Source and feedback

Downloads include patches, installation notes, checksums, a build manifest and validation record. GitHub's automatic source archive contains the toolchain, English-only script exports and docs. It contains no original disc image or Japanese script dump, and needs a local dialogue-font cache for a full rebuild.

The translation was machine-produced and then edited; it has not been fully proofread against Japanese by a fluent human translator. Earlier translation passes and reverse engineering used Claude; the ending tracker and punctuation correction were prepared with Codex, directed by pow. The dialogue font comes from Skies of Arcadia (SEGA); movie/ending text uses Noto Sans (SIL OFL).

Bug reports, proofreading and playtesting are welcome on [Discord](https://discord.gg/nZBZfTDfCP). The patch is free: do not sell it or anything made with it.
